사내 현장정보 업무포털 - 수정본 V2

[이번 수정의 핵심]
1. 회사 직원 전용
- Supabase Auth ID/PW 로그인 사용
- pjt_profiles의 approved + can_use_staff_portal 권한을 모두 통과해야 접속 가능
- 회사 외부인은 관리자 등록 없이는 계정을 만들 수 없음
- 회원가입 화면 없음

2. 사용자 관리
- 관리자만 사용자 관리 메뉴 접근
- 관리자가 직접 사원명, ID, PW, 전화번호 입력하여 계정 생성
- 관리자/일반 사용자 구분
- 승인, 포털 사용, 현장검색 권한 설정
- 관리자 계정에는 매출관리/엑셀 DB등록/사용자관리 권한 자동 부여
- PW 초기화, 계정 삭제 지원

3. 현장 검색 DB
- 확정수량.xlsx의 진행중 시트 A~EG 137개 업무 열을 staff_site_source에 저장
- 일반 직원 검색용 staff_site_search는 금액 열을 제외한 별도 테이블
- 날짜 열만 날짜로 변환하도록 수정 (연면적 등 일반 숫자를 날짜로 오인하던 문제 수정)
- 새 엑셀을 다시 가져오면 import_token 기준으로 기존 DB와 완전 동기화하여 삭제된 현장이 남지 않음
- Sheet1(B5:O17)은 부가 시트 데이터로 staff_workbook_meta에 함께 저장
- 현재 첨부 파일 기준 현장 데이터: 5,742건

4. 현장 검색 기능
- 현장명, 계약명, 지역, S/N, 문서작성 담당, 현장점검원 검색
- 전체 / 전체 진행 중 / 점검대상 / 점검 진행 중 / 점검 완료 / 보고서 미작성 / 보고서 완료 필터
- 표시항목 선택 저장
- 상세조회:
  · 기본정보
  · 진행·담당·계약
  · 유지관리 대상 전체수량
  · 성능점검 대상수량
  · 성능점검 확정수량

5. 매출 관리
- 관리자만 사용 가능 (화면 + DB RLS 이중 제한)
- 연도 / 월 / 문서작성 담당 / 현장명 검색
- 매출 건수, VAT 미포함 매출액, 제본비, 보고서 완료 건수 집계
- 현장별 매출 표
- 출력
- 엑셀 내보내기
- 확정수량.xlsx 엑셀 가져오기 = 전체 현장 DB 갱신
- 1,000건 제한 없이 전체 자료를 페이지 단위로 조회하도록 수정
