# V98 보고서 연결 프로그램 설치 안내

현재 포털에는 보고서 버튼과 관리자 연결 설정 화면이 추가되어 있습니다. 실제 NAS 접속은 하지 않았으며 reportApiUrl은 공란입니다. 연결 프로그램 설치 전에는 준비 상태 안내가 표시됩니다. NAS 관리자 암호는 어떤 배포 파일에도 포함하지 않았습니다.

## 구성

- 포털: 현장 검색 목록과 상세 조회의 보고서 버튼, PDF 열람/다운로드, 관리자 현장 폴더 연결.
- 연결 프로그램: server.py. NAS가 드라이브 또는 폴더로 연결된 PC/서버에서 실행합니다. 직접 FTP 로그인하는 프로그램은 아니며, OS가 이미 연결한 NAS 폴더를 읽습니다.
- 연결 정보: private/report-links.sqlite. 등록 건별 DB 현장 ID에 폴더·기준일·우선 파일명을 저장합니다. NAS 파일은 수정하지 않습니다. 이 DB는 정기 백업 대상이며 웹에 공개하면 안 됩니다.
- 실제 NAS에 접근 가능한 PC/서버가 계속 켜져 있어야 합니다. ipDISK 연결 드라이브는 프로그램을 실행하는 동일 사용자에게 보여야 합니다. Windows 서비스 계정에는 Z 드라이브가 보이지 않을 수 있으므로 실행 계정의 경로 확인이 필요합니다.

## 설치 순서 (서버 연결 확인 후 담당자가 진행)

1. NAS 연결 확인은 사용자 승인 범위에서 별도로 진행합니다. 포털 연결 프로그램 실행은 이후 실제 운영 설정으로 진행합니다.
2. NAS에 접근 가능한 PC에 Python 3.10 이상을 준비합니다. 추가 pip 패키지는 필요 없습니다.
3. report-bridge 폴더는 공개 웹 배포 폴더 밖의 비공개 위치에 보관합니다.
4. config.example.json을 config.json으로 복사합니다.
5. nas_root를 실제 읽을 수 있는 NAS 기준 폴더로 설정합니다. 상록중학교 예시에서는 Z:\VOL1입니다. 반드시 실제 경로를 확인한 후 사용합니다.
6. allowed_origins에는 실제 포털의 주소를 https://도메인 형태로 넣습니다. 경로 또는 마지막 /는 넣지 않습니다. 와일드카드 금지.
7. supabase_key에는 포털 config.js의 publishable key를 복사합니다. service_role 또는 NAS 관리자 암호를 사용하지 않습니다.
8. 연결 프로그램 폴더에서 python server.py --config config.json 실행합니다. 기본적으로 127.0.0.1:8787에서만 대기합니다. 프로그램은 접속 요청을 받을 때 승인된 포털 사용자와 현장 존재 여부를 Supabase에서 확인합니다.
9. 운영 접속에는 HTTPS 리버스 프록시 또는 인증된 사내 연결 경로를 구성합니다. 외부 도메인/인증서/사내 네트워크 연결 방식은 서버 환경 확인 후 결정합니다. Python 내장 서버를 직접 인터넷에 노출하지 않습니다. 운영용 프로세스 감독 및 접속 제한은 배포 담당자가 구성합니다.
10. 포털 config.js의 reportApiUrl에 연결 프로그램의 HTTPS 기본 주소를 입력합니다. /api/sites는 붙이지 않습니다. 포털 주소와 allowed_origins가 일치해야 합니다.
11. 포털 관리자로 현장 선택 → 보고서 → 관리자 현장 보고서 폴더 연결 → 상대경로·기준일 저장 → 보고서 다시 조회.

## 상록중학교 예시

NAS 기준 폴더: Z:\VOL1
현장 폴더 상대경로: 유지관리 및 성능점검/② 학교/상록중학교
성능 실시기준일: 2025-04-18
우선 파일명: 제5권 기계설비 성능점검 보고서-상록중학교(기준일 25.04.18).pdf

폴더를 연결할 등록 건의 실시기준일을 확인하세요. 우선 파일명은 표시 순서를 정하며, 같은 날짜의 여러 후보 중 다른 파일을 자동으로 단정하지 않습니다. 기준일은 파일명에 25.04.18/2025.04.18/2025-04-18 등 숫자가 포함된 후보를 필터링합니다. 파일명에 날짜가 없으면 기준일을 공란으로 두고 현장 내 목록을 확인합니다.

업무 폴더명 03 진행→04 완료처럼 현장 폴더 내부의 폴더가 바뀌면 다시 조회하여 새 위치를 찾습니다. 현장 폴더 자체가 이동/변경되면 관리자가 상대경로를 수정해야 합니다. 포털 현장명 변경은 DB 현장 ID 연결에 영향을 주지 않습니다. 파일명 자체가 바뀌면 목록과 기준일 조건을 확인하세요.

## 범위와 제한

조회 및 다운로드만 지원합니다. 업로드/삭제/NAS 설정 변경 기능은 없습니다. PDF는 새 창에서 열고 기타 지원 문서는 다운로드합니다. 한글/엑셀 웹 미리보기는 없습니다. PDF 새 창이 차단되면 팝업을 허용해야 합니다.

기본 한도: 폴더 10단계, 검색 10,000파일, 후보 500개, 검색 15초(파일시스템 응답 지연 시 더 길어질 수 있음), 다운로드 200MB. 큰 파일은 ipDISK로 이용합니다. NAS 파일 접근은 프로그램 실행 계정의 OS 권한에 따르므로 읽기 전용 계정/폴더 연결을 권장합니다.

SQLite 연결 정보는 포털 DB와 별도입니다. 자동으로 기존 모든 현장의 폴더를 연결하지 않습니다. 관리자가 각 등록 건에 현장 폴더와 기준일을 설정합니다.

프로그램 업데이트 시 config.json과 private 폴더는 보존합니다. 포털 배포에는 최상위 웹 파일만 교체하고 report-bridge 폴더는 공개 배포하지 않습니다. 서버 접속정보는 포털 JS/HTML에 기록하지 않습니다.

검증: 임시 폴더와 모의 인증 응답으로 폴더명 변경, 날짜 구분, PDF 바이트 전달, 미로그인/조회 권한 없는 사용자/관리자 아닌 설정 변경 차단, 경로 이탈/외부 링크 차단 확인. 실제 NAS와 운영 Supabase 권한 응답, HTTPS 배포 및 브라우저 PDF 표시/휴대폰 동작은 미검증입니다.

시험: python -m unittest discover -s . -p "test_*.py" -v
